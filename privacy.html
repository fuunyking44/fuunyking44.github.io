Small Browser Tools

Privacy policy

Last updated 25 October 2026

The short version. Files you open in a tool on this site are read by your own browser and never sent anywhere. There is no account, no upload endpoint and no server that stores your data. This site has no analytics and no tracking scripts.

Files you open in the tools

Every tool here is a single HTML file. When you choose a file, the browser reads it into memory using the standard File API and the work is done locally — resizing on a canvas, or parsing a PDF structure in JavaScript. No request containing your file is made to this site or to any third party. If you are offline after the page has loaded, the tools still work.

Closing the tab clears the data. Nothing is written to a database, because there is no database.

What the hosting provider sees

This site is served as static files by GitHub Pages. Like any web host, GitHub receives the ordinary technical information involved in delivering a page — IP address, browser user-agent, the URL requested, and the date and time. That is standard server logging controlled by GitHub, not by this site, and it is described in GitHub's own privacy statement. This site does not add cookies or identifiers of its own.

Cookies

This site sets no cookies and uses no local storage to identify you. If advertising is introduced in future, third-party vendors — including Google — may use cookies to serve ads based on prior visits to this or other websites, and Google's use of advertising cookies enables it and its partners to serve ads to you. You can opt out of personalised advertising through Google Ads Settings. This paragraph is here so the policy stays accurate if that changes; as of the date above, no advertising code runs on this site.

Links to other sites

Some pages link to external documentation, such as a platform's official help centre. Those sites have their own privacy practices, which this policy does not cover.

Children

This site is a set of general-purpose file utilities and is not directed at children. No personal information is knowingly collected from anyone, because no personal information is collected at all.

Your choices

Because no personal data is collected or stored by this site, there is nothing to request, correct or delete. If you believe otherwise, the about page lists how to get in touch, and it will be looked into.

Changes

If this policy changes, the date at the top changes with it. Material changes — for example adding analytics or advertising — will be stated plainly on this page, not buried.

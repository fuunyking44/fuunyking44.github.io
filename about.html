Small Browser Tools

About this site

A small collection of single-purpose browser tools, plus a reference page that documents the numbers other guides keep getting wrong.

Why it exists

Most “free online converter” sites work the same way: you upload your file to someone's server, wait, get back a lower-quality version, and are then asked to pay to remove a watermark or to unlock the size you actually needed. For a 40 KB emote or a PDF you were sent by a client, that is a bad trade — you are handing over a private file to save yourself thirty seconds.

Every tool here is a single HTML file. It reads your file with the browser's own APIs, does the work locally, and hands it back. There is no upload endpoint, because there is no server doing the work. That also means there is no cost per file, so there is no reason to meter you, watermark you or cap your file size.

How the tools are built

No uploadProcessing happens in your browser. The tools keep working if you go offline after loading the page.
No accountNothing to sign up for, nothing to log in to, no email required.
No watermarkOutput is your file, not your file plus branding.
No size paywallThe limits in the tools are the platform's real limits, not a business model.

How the reference numbers are checked

The emote and badge size reference is the one page here that is not a tool. It exists because most published size charts are copied from each other rather than from the platforms, and the copies drift. The 7TV upload limit in particular is quoted as 2.5 MB by several well-known emote tools; 7TV's own help centre says 7 MB.

The method is deliberately boring: read the platform's own documentation where it exists, otherwise read the validation rules the upload form actually enforces, cite which one was used, and date the page so a reader can judge how stale it is. Where a number is uncertain — Kick's upload ceiling changes more often than the others — the page says so instead of printing a confident figure.

Corrections

If a number on this site is wrong, it is worth fixing, because a wrong specification costs someone an upload attempt or a rejected emote. Corrections are welcome through the GitHub account that hosts this site: @fuunyking44. Please include a link to the page you are correcting and, if possible, the source that shows the correct value.

Who maintains it

One person, independently. The site is served as static files from GitHub Pages and has no analytics, no tracking scripts and no advertising at present. The privacy policy explains exactly what that means for your data — which is, essentially, nothing beyond the ordinary logs any web host keeps.
